# Twitch Chat Translator requests

Where user requests for [Twitch Chat Translator](https://github.com/kilworks/twitch-chat-translator) are kept, with the research done to try to satisfy each one.

A request comes from a store review, a support question or an issue. Each one gets a case file in `cases/`: what was asked, what could be measured, what was changed, what was proven and what was not. The cases are worked examples of the method (sets frozen by hash, a decision rule written before scoring, controls that must fail first, counts only) used in the [research study](https://github.com/kilworks/kick-translator-research).

| Case | Request | State |
|---|---|---|
| [001](cases/001-han-script-detection.md) | Lines in languages written with Han characters are not detected correctly and are not translated | First change merged in the Kick extension, in review in the Twitch extension; second change a draft |

No chat lines, names or personal data are stored here.
